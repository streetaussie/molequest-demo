# MoleQuest Demo

A reader-free, touch-friendly molecule-building game demo for phones, tablets, and desktop browsers. It contains no registered RFID tag IDs or reader settings.

The GitHub Actions workflow publishes the static web app to GitHub Pages whenever changes are pushed to `main`. After Pages finishes its first deployment, open the published HTTPS URL in Safari on iPhone or iPad and choose **Share → Add to Home Screen → Open as Web App**.

The app uses on-screen virtual element cards and caches its files for offline use after the first successful load.
